# Data Directory

This directory contains the **raw dataset** used by the Mwalika Agent.

The data was collected via a structured web scrape of publicly available
information from the Kenyan eCitizen ecosystem, including ministries,
agencies, and associated government services.

The dataset in this repository is treated as the immutable input layer
for corpus processing and embedding generation.

## Source Repository

All detailed documentation regarding:

- Data collection methodology
- Scraping logic
- Data schema
- Licensing considerations
- Attribution notes
- Ethical and legal considerations

is maintained in the dedicated dataset repository:

<https://github.com/karaalv/kenya-ecitizen-services-dataset>

Please refer to that repository for all dataset-specific licensing
information and documentation.

## Important

This repository does **not** define the licensing terms of the dataset
itself. The dataset licensing and documentation are governed by the
`kenya-ecitizen-services-dataset` repository.
